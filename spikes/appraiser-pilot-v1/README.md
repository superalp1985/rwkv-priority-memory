# 四维评分器：第一轮资格试验

本目录不修改 `appraise()`、校准程序或 RWKV 权重。使用离线代理任务，检验一个小型上下文评分器是否值得采集下一阶段的项目标签。不会把测试样例的预期、模拟标记或人评其他任务的分数当成本项目金标。

| 项 | 固定训练输入 | 冻结的检查 |
| --- | --- | --- |
| 重要性代理 | Memora 非删除会话的原始用户轮；最多六条历史发言在前、当前目标在后；只有模拟对话的 `share_memory` 作二元弱标签。训练用 6 个 quarterly persona，开发和测试各用 2 个不同的 weekly persona。 | 留出 AP 高于正例率与仅按目标字符数排序的 AP；另报 AUROC、删去上下文重算 AP。相同原话跨 split 的归一化精准匹配全部去除。不承诺语义或模板级隔离。 |
| 情绪代理 | SemEval 2025 Task 11 Track B `chn` 官方 train/dev/test 的文本本身；不含对话上下文。输出六种感知情绪各自的 0–3 档位分布。中文项目诊断另提供带角色的历史上下文，再将目标文本置于后段。 | 留出六类期望值的 macro Pearson ≥ 0.25，且高于字符数排序；同时报离散 Pearson、各维 MAE/正例 MAE、训练中位数基线和无支持档位。该任务不直接等同项目定义的单一用户表达强度 `E`。 |
| 中文项目反例 | 独立 `pairs.json`，不接触训练和开发。两端使用同一模型和设置。 | 每类四对，高端至少领先 0.05（归一化到 0–1），持平和缺失为失败。重要性用代理概率；情绪用六类期望值最大值**仅作诊断**，并显式记录能否区分引用与本人。 |
| 重复、时效 | 给定已核对的事项版本、用户轮 ID 与 UTC 时间。 | 只计原始用户提及；重放、助手复述、检索、更正后的另一版本不计；时间推进不刷新提及时间。输出计数及距最后一次提及的秒数，不擅自把它们映射为项目的 0–4 分。 |

基座 `FacebookAI/xlm-roberta-base` 固定 revision。两项独立训练以便定位失败，更新最后两层和对应线性头；两轮，按开发集指标选轮，只用冻结后的模型测测试集。权重和数据放 `/data`，不上传。Memora 数据是模拟标注；BRIGHTER 原文限定科研、不可再分发，此处只进行本机研究。判定代理能跑不等于可部署或可商用。

**放行规则：** 即使代理成绩和反例均通过，也要用未参与训练的中文逐事项、有角色与前文的独立人工评级验证 `I`/`E` 的项目量表，并校验 `F`/`R` 的等级口径和真实评估器输入。缺项保持待评；不把代理分数四舍五入交给旧校准器。外部 XLM-R 读取文本不是本项目“RWKV 在当前 state 上自评”的等价验证。
