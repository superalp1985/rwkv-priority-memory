# 真人记忆偏好试标协议

## 目的

判断哪种有限工作记忆更接近人的使用习惯，而不是猜模型答案对不对。分别考察：

1. 下一次相关交流前，哪些事项值得留在随手可用的工作记忆。
2. 哪些细节只应在获授权的完整原文档案里留着，等问到再查。
3. 哪些信息不应主动提起，或已失效、不该继续当成当前规则。
4. 匿名策略输出中，哪一组最适合带入下一轮。

本批七题有五题三组卡片完全相同或全空，只有两题可以区分策略；该结果来自实际回放输出，标注在 Phase 2 表中。

## 盲评流程

- 由两位评审分别完成；先不要互相讨论，也不要看模型报告、策略名称、作者预期标签或对方答案。
- **先只发 Phase 1**（[独立记忆标注表](../reports/human-rating-phase1-v1.md)）。不要打开 Phase 2。评审每题先自由写下会带进下一次相关交流的事项；之后才看候选卡、在一个工作记忆位的约束下至多选一张。可选“都不留”。
- Phase 1 完成后收回或锁定，才发 [Phase 2 匿名输出表](../reports/human-rating-phase2-v1.md)。输出 A/B/C 每题独立置换策略标签，真实对应只保存在主持人密钥中；卡组可能相同，也可能为空。对每组单独评分，再选最佳、平局或都不合适。
- 不要求猜后续会问什么。一个卡片“留在工作记忆”不等于允许无关时主动提起。Phase 2 不提供任何模型生成的回复，所以不能评价实际打扰或自然沿用。
- 这些中文对话和卡片是英文试验材料的意译。第一阶段是人的偏好标注，不是 RWKV tokenizer 的容量实验。第二阶段的原始英文回放使用同一个 24-token 预算；译文仅用于判断卡片含义。

## 记录方法

每题分别填写：工作记忆候选、仅保留原文待询问时查的细节、已经过时/可舍弃事项，以及信心 `1–5`。若相同信息有范围或时间边界，必须把边界写进卡片。空白和“都不留”是有效答案。

Phase 2 对 A/B/C 各打 `1–5`：`1` 很不合用，`3` 可接受，`5` 很合用。再选 `A / B / C / 平局 / 都不合适`，并简述最重要的取舍。不可把空卡组自动视为好或坏；应结合当前对话判断。

先报告两位评审的逐题选择、完全一致、并列/都不合适和分歧；试标只有 7 个检查点，不能据此计算有意义的显著性或发布策略胜负。未来扩充应以整段对话为单位留出配对样例，并加入自然回复盲评。本次卡片试标的主问题是评审想把什么带入下一轮；它只是记忆习惯的一个必要观察，不单独决定策略胜负。最终验收需在留出的真实交互轨迹中，盲评各策略的完整回复：是否自然沿用有效约定、是否立即采用更正后的版本、是否在无关话题里硬提旧事，以及被问到精确历史时是否按需查原文并给出依据。按整段对话记录人类偏好、平局和分歧。以上行为当前均未实现或测量；问答正确率仅作次指标。

## 解释边界

固定权重回放本身已经公开在 [VALIDATION.md](VALIDATION.md)。它的目标卡、等级概率和各策略输出都不能作为真人标注答案。`local/human-rating-key-v1.json` 保存 A/B/C 与臂的对应，主持人保管，不发给评审。解盲前先锁定两位评审表；解盲后报告原始分歧，不覆盖原答案。
